# Sample data

Synthetic sample data, written by hand for this repository so the stage manager can start without a real song library.

- `songs/sample-1..3/`: three made-up songs. Each has a `song.ini` and a 16-note `notes.chart` in Clone Hero's
  text chart format. There is no audio, and the titles and artists are placeholders. They exist so the sign-up page
  has a song list; they are not meant to be played.

Nothing here comes from a real show.
